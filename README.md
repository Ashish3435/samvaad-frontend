# 💬 Samvaad – Modern Real-Time Chat Application

![Version](https://img.shields.io/badge/version-v1.0.0-blue)
![React](https://img.shields.io/badge/React-18-61DAFB?logo=react)
![Vite](https://img.shields.io/badge/Vite-7-646CFF?logo=vite)
![TailwindCSS](https://img.shields.io/badge/TailwindCSS-4-38B2AC?logo=tailwind-css)
![License](https://img.shields.io/badge/license-MIT-green)

Samvaad is a modern real-time messaging application inspired by Discord, Slack and WhatsApp.

This repository contains the **React + Vite frontend** of Samvaad.

---

# ✨ Features

## ✅ Version 1.0

- 🔐 JWT Authentication
- 👤 User Registration & Login
- 💬 One-to-One Chat
- 👥 Group Chat
- 📢 Channels
- ⚡ Real-time Messaging using WebSockets
- ✅ Message Seen Status
- 🟢 Online User Status
- 📱 Responsive UI
- 🌙 Modern Dark Theme

# ⚙ Installation

Clone the repository

```bash
git clone https://github.com/Ashish3435/samvaad-frontend.git
```

Go inside the project

```bash
cd samvaad-frontend
```

Install dependencies

```bash
npm install
```

Run locally

```bash
npm run dev
```

Build

```bash
npm run build
```
